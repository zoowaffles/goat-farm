# 🐐 किसान गोट फार्म (Kisan Modern Goat Farm Website)

हा प्रकल्प एका उच्च दर्जाच्या आणि व्यावसायिक (₹३५,००० ते ₹४०,००० किमतीच्या) शेळीपालन वेबसाइटसाठी तयार केलेला आहे. हे कोड पूर्णपणे **GitHub Pages** किंवा कोणत्याही वेब होस्टिंगवर चालवण्यासाठी तयार आहे.

---

## 🌟 मुख्य वैशिष्ट्ये (Key Features)

1. **आधुनिक व प्रीमियम UI/UX**: हिरवा व सोनेरी शेती-आधारित आधुनिक रंगसंगती, ग्लासमोर्फिझम आणि गुगल फॉन्ट (Mukta & Outfit).
2. **इंटरअॅक्टिव्ह शेळी फिल्टर (Breed Catalog)**: सिरोही, बोअर, उस्मानाबादी, बीटल या जाती एका क्लिकवर फिल्टर करण्याची सुविधा.
3. **थेट अंदाजपत्रक कॅल्क्युलेटर (Live Price & Weight Calculator)**: वजन आणि नगांनुसार थेट गुंतवणुकीचा अंदाज आणि व्हॉट्सॲप मेसेज जनरेटर.
4. **थेट व्हॉट्सॲप इंटिग्रेशन**: सर्व बटणे आणि फॉर्म्स थेट WhatsApp API शी जोडलेले.
5. **नेहमी विचारले जाणारे प्रश्न (Interactive FAQ Accordion)**.
6. **१००% मोबाईल व टॅबलेट फ्रेंडली (Fully Responsive)**.

---

## 🚀 GitHub वर कसे अपलोड करावे (How to Deploy to GitHub Pages):

1. **GitHub वर लॉगिन करा** आणि नवीन रिपॉझिटरी (Repository) तयार करा (उदा. `goat-farm-website`).
2. या फोल्डरमधील सर्व फाइल्स (`index.html`, `style.css`, `script.js`, `README.md`) तुमच्या रिपॉझिटरीमध्ये अपलोड / पुश करा.
3. Repository च्या **Settings** मध्ये जा -> **Pages** वर क्लिक करा.
4. **Branch** मध्ये `main` किंवा `master` निवडा आणि **Save** वर क्लिक करा.
5. १ मिनिटात तुमची वेबसाइट लाईव्ह होईल (उदा. `https://username.github.io/goat-farm-website/`).
